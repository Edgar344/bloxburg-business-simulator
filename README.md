# Bloxburg Business Simulator

This project is a simple Java program that shows how object-oriented programming works. The main file (`BloxburgGame.java`) lets the user create a business and see how taxes and employees work.

## Core Features & Concepts Used

* **Method Overloading:** I created a `Business` class with overloaded constructors to allow businesses to be initialized with different sets of parameters.
* **Static Fields:** Implemented a static counter (`totalBusinesses`) to track the total number of business instances created across the application.
* **Nested Classes & Composition:** Built a nested `Employee` class inside `Business` to manage employees and track their details within each business.
